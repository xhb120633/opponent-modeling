# Released row-level development outputs

These files are selected to make Figure 2 live-play summaries and central Figure 3/4 point estimates recalculable without model access. `SOURCE_MANIFEST.json` records the original and released SHA-256 for each. They are not sealed-final data, and no original project paths or account credentials are included.

| Paper panels | Released files under `raw/` | Included observations |
|---|---|---|
| Figure 2A | `figure2a_qwen25_tom2_match_scores.csv` | 20 match-level payoff and action-accuracy rows for each of 14 plotted Qwen2.5 seeker/hider cells against ToM2; filtered from the consolidated source table, not original round replies |
| Figure 2B | `figure2b_tom2_hider/{oss_low,oss_medium,oss_high,gemma_thinking}.csv.gz`; paired audits in `results/audited_live_cells/` | Four audited 20-match hider-versus-ToM2 cells; 1,000 rounds each, including original model replies, prompts and opponent-state fields |
| Figure 2C | `figure2c_gpt54_{seeker,hider}/matches/{action_only,structured}_00..19/{rounds.csv.gz,requests.jsonl.gz}`, with `audit.json` and `match_summary.csv` in each role folder | 20 matches of 50 rounds per role and output condition; 4,000 rounds, with prompts, raw replies and request journals |
| Figure 3a,b,d | `figure3_t04/action/responses.jsonl`, `figure3_t04/belief/responses.jsonl`, `figure3_t04/audit_metrics.json` | 240 response records per stage; six 60-decision model/control groups with row-level predictions and targets in the audit |
| Figure 3e,f | `figure3_r5/known/initial_A_fresh.jsonl`, `figure3_r5/known/eval_fresh.jsonl`, `figure3_r5/mixed/eval_fresh.jsonl`, `figure3_r5/audit_20260918.json` | Three 1,200-row fresh-cohort files, containing known and history-only inputs; 540 noninitial decisions per information condition |
| Figure 4d,e | `figure4_intervention/requests.jsonl`, `figure4_intervention/responses.jsonl`, `figure4_intervention/scored_rows.json`, `figure4_intervention/audit_results.json` | Six 54-decision supplied-information arms, plus separate replication records; prompts, raw replies, scored decisions and audit summaries |

Figure 2A rows are filtered match-level metrics; the manifest records the source-table hash and exact transformation. Figure 2B compressed CSVs are byte-preserved. For Figure 2C, the sole content edit is a literal replacement of an account-specific GPT deployment identifier with `gpt-5.4`, including nested history fields; numerical and behavioral fields are unchanged. The manifest gives both the original audit-bound file hash and the released file/uncompressed-content hashes, plus the replacement count. `reanalyse_live_raw.py` checks Figure 2A means and Figure 2B/2C per-match and arm-level payoff/accuracy against the plotted values and audits. `reanalyse_selected_raw.py` checks Figure 3/4 hashes where recorded in the audits and recomputes point estimates from included rows. Neither regenerates simulator targets from histories, verifies every model checkpoint, reruns an API/local model, or recomputes every confidence interval. The remaining panels have code and plotted-value provenance but not all row-level records. Never interpret absence of a raw file as a zero or a failed result.
